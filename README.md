### Why this journey?
The old “learn Python → build To-Do app → junior dev” path is dead in 2026.  
I’m following a custom AI-Native roadmap (made with Gemini’s deep research) focused on:

- Async-first Python (agents must run in parallel)
- Structured outputs with Pydantic + Instructor
- Local-first LLMs (Ollama)
- Agentic orchestration, rigorous evals, and domain grounding

This repo is my **living portfolio** — every line of code, every lesson, every mistake.
