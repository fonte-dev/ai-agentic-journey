# Day 22 - The Triage Simulation (Planning)
# Task: Project Planning: Design "The Triage Simulation." 100 patients arrive randomly. 3 doctors process them.
# Learning goal: Design Phase: Mapping the architecture before coding.
# Date: Feb 2026
# Status: Done ✅


1. Patients Entity (Class) (Arriving randomly) (Data-Producer)
Needs to carry:
- p_id: int
- name: str
- arrival_time: time.time()
- severity: int (1:5) 1 is Critical

2. Doctors Entity (Coroutine) (Worker-Consumer)
Needs to carry:
- d_id: int
- name: str
- wait_time = time.time() - arrival_time
- discharge_time: time.time() - wait_time
- treatment: dependent on severity asyncio.sleep(5:1 for 
severity 1:5)

3. The Hospital/Triage Environment (State & Flow)
-> Producer: Patients: Creates 100 of them that arrive at random 
intervals between 1:3 in between each other. At each arrival a 
print of the time of it.
-> Waiting Room (queue): Each patient gets added to it thru 
asyncio.Queue. asyncio.PriorityQueue if severity 5
-> Consumer: Doctors: Creates 3 of them that run in a coroutine 
in a for all the time until waiting room is empty and all patients 
(tasks) are done. At each start and end theres a print with the 
time of starting treatment and discharge.
